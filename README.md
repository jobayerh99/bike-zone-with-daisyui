# 🏍️ Bike Zone — Motorcycle Landing Page

A responsive motorcycle landing page built with **HTML, Tailwind CSS, and DaisyUI**. Bike Zone features a modern layout with a hero carousel, featured motorcycle cards, customer testimonials, and an FAQ section.

## 📸 Project Overview

Bike Zone is a clean and modern motorcycle landing page designed to showcase bikes and provide visitors with an engaging browsing experience. It uses Tailwind CSS utility classes and DaisyUI components to create a responsive interface with a consistent visual style.

## ✨ Features

- **Responsive Navigation:** Navigation menu with mobile dropdown support.
- **Hero Carousel:** Four motorcycle banner slides with previous and next navigation.
- **Latest Bikes:** Motorcycle cards with images, titles, descriptions, and action buttons.
- **Customer Testimonials:** A dedicated section featuring customer feedback and star ratings.
- **FAQ Section:** Expandable accordion-style questions about motorcycle riding and safety.
- **Responsive Layout:** Grid and flex layouts that adapt to different screen sizes.
- **Custom Theme:** Consistent primary color and typography throughout the website.

## 🛠️ Technologies Used

- **HTML5** — Page structure and semantic elements.
- **Tailwind CSS** — Utility-first styling and responsive layouts.
- **DaisyUI** — Prebuilt UI components such as navbar, carousel, cards, rating, and accordion.
- **Google Fonts (Poppins)** — Website typography.
- **Custom CSS** — Font styling and small design customizations.
